Este tutorial leva você do "o que é Git?" até o fluxo de trabalho de um time, em
oito capítulos. Cada capítulo segue a mesma ordem: **objetivo → conceito → passo
a passo → o que pode dar errado → resumo**.

Se você já sabe o básico e só quer o comando, vá direto para a
[referência de Git](/DevGuia/git/referencia/).
