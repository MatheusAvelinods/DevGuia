Este tutorial leva você do "o que é um container?" até um ambiente com vários
serviços no Docker Compose, seguro e enxuto. Cada capítulo segue a mesma ordem:
**objetivo → conceito → passo a passo → o que pode dar errado → resumo**.

Se você já sabe o básico e só quer o comando, vá direto para a
[referência de Docker](/DevGuia/docker/referencia/).
